# CareerForge: five-student usability test
Use five volunteers, identified only as S1–S5. Allow 15–20 minutes each.
Use a sample resume or remove personal contact details from a real resume.
Do not collect passwords or reset links. Explain that this is a beta.

Without coaching, ask each student to:
1. Sign in and add a resume, or enter skills manually.
2. Choose a role and find the next learning task.
3. Open its resource, attempt a small exercise, and record a short practice review.
4. Start a five-question interview, save an answer, leave, and resume it.
5. Finish practice, find what to improve, and open a relevant learning task.
6. Paste a sample job description and find the first suggested improvement.

For each task record: completed without help / needed help / blocked; time; confusing wording;
device/browser; error seen. Confirm progress survives refresh and signing in again.
Ask: What would you remove? What did you expect next? Would you use this next week?
